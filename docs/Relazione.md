# Indice

# 1. Introduzione
## 1.1 Statement
Il progetto modella un'applicazione software per la gestione di una libreria personale di videogiochi. Il sistema permette agli utenti di catalogare i titoli posseduti o desiderati, inserire valutazioni e monitorare lo stato di completamento.
La piattaforma offre funzionalità di organizzazione della collezione tramite categorie e piattaforme, fornendo inoltre statistiche relative all'attività videoludica per permettere all'utente di tracciare i propri progressi nel tempo.
